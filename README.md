# 芯云小天才分享Pro（XTC Share Pro）

小天才手表 **XTC 分享应用**，支持将图片、视频、链接、应用一键分享到小天才 **微聊** 与 **好友圈**。

- 包名：`corecloud.xtc.share`
- 版本：1.2（versionCode 7）
- 最低系统：Android 6.0（minSdk 23）
- 架构：armeabi-v7a（32 位）

## 功能

| 页面 | 功能 | 说明 |
|---|---|---|
| 文本页 | 分享文本到微聊 | 原有功能 |
| 图片页 | 选择图片 / 分享图片 | **已补齐**：点击选择图片，点击分享到好友圈，长按分享到微聊 |
| 视频页 | 选择视频 / 分享视频 | **已补齐**：点击选择视频并自动生成缩略图，点击分享到好友圈，长按分享到微聊 |
| 链接页 | 分享链接 / 链接列表 | 原有功能 |
| 应用页 | 分享应用到微聊 / 好友圈 | 原有功能 |
| 设置页 | 应用名称 / 图标 / 介绍图 / 还原配置 | **已补齐**：保存自定义应用名称，设置分享图标与介绍图，一键还原默认配置；设置背景为原有功能 |

## 本次修复内容（相对 1.2 原版）

1. **图片页 / 视频页**：原“选择图片 / 选择视频 / 分享”按钮无响应（仅弹“功能正在施工中”），已接线实现完整分享流程。
2. **设置页**：保存（自定义应用名称）、设置图标、设置介绍图、还原默认配置 4 个按钮全部实现。
3. **应用分享联动**：设置页自定义的应用名称、图标、介绍图会实际生效于“分享应用”功能。
4. **安装兼容性修复**：修复重打包后 native 库（`libwebp.so`）未页对齐导致的 `INSTALL_FAILED_INVALID_APK: Failed to extract native libraries` 安装失败问题（对齐至 4096 字节页边界，与官方构建一致）。

## 安装

直接安装 `芯云小天才分享Pro_1.2_完成版.apk`。

> ⚠️ 本版本使用新的调试签名密钥，无法覆盖安装旧版；安装前请先卸载旧版本，或使用你自己的签名密钥重新签名。

## 工程结构

```
src/
  ShareHelper.java   # 新功能核心：选择结果路由、图片/视频分享、配置读写
  n3.java            # 新功能点击监听器（各按钮接线）
  n4.java            # 新功能长按监听器（微聊快捷分享）
```

其余界面逻辑基于原版 APK 反编译字节码补丁实现，未改动原有功能。
